# Indian Stock Swing-Trading Scanner & Research Platform (NSE/BSE)

A production-grade quantitative swing-trading research terminal and scanner built for Indian equities. Engineered specifically for individuals with 9-to-5 responsibilities who review setups after market close (3:30 PM IST) and execute structured orders before the next morning's market open.

> **DISCLAIMER:** This software is strictly for quantitative research and educational purposes. Historical backtests do not guarantee future performance. No signal generated by this system guarantees profit. Algorithmic setups express probabilistic degrees-of-fit to predefined rules, not market certainties. Live broker order execution is intentionally disabled (`LIVE_TRADING_ENABLED=false`).

---

## Key Capabilities

1. **Robust Data Validation Pipeline:** Validates raw daily OHLCV candles to catch missing candles, duplicate dates, impossible OHLC values ($High < Low$), zero or negative volume, and abnormal price jumps ($>35\%$ unadjusted splits/spikes).
2. **Deterministic Market Regime Engine:** Evaluates broad market momentum on NIFTY 50 (`^NSEI`) into `BULLISH`, `NEUTRAL`, or `BEARISH` based on multi-timeframe moving average alignments and RSI. Signals are adjusted rather than blindly discarded during corrections.
3. **Point-in-Time Technical Calculations:** Features pre-computed indicators (SMA 20/50/200, EMA 20/50/200, RSI 14, ATR 14, ADX 14, MACD, Volume SMA 20, Relative Volume, 20d Volatility, Rolling Swing Highs/Lows) strictly computed without look-ahead bias.
4. **TREND_PULLBACK_V1 Strategy:** Identifies liquid stocks in a confirmed medium-term uptrend undergoing controlled pullbacks to key moving averages (EMA 20 / EMA 50) with bullish reversal or breakout confirmation.
5. **Multi-Factor Scoring (0–100):** Candidates are scored across 7 transparent dimensions (Trend 25%, Momentum 15%, Pullback Quality 20%, Volume Confirmation 15%, Breakout 10%, Regime 10%, Liquidity 5%).
6. **Market Structure Risk & ATR Sizing:** Stop losses and profit targets adapt to market structure (recent swing lows + ATR buffers) with mandatory $\ge 1:2.0$ Risk/Reward ratios.
7. **Institutional Indian Equity Friction Model:** Backtests deduct realistic delivery costs: Securities Transaction Tax (STT 0.1% buy + 0.1% sell), NSE exchange charges (0.00345%), GST (18%), Stamp Duty (0.015%), CDSL/NSDL DP charges (₹15.93 flat per sell), and slippage (0.1%).
8. **Event-Driven Backtest & Walk-Forward Validation:** Guarantees zero look-ahead bias (signals generated at Day $T$ close enter strictly at Day $T+1$ Open) and tests out-of-sample periods with survivorship bias warnings.
9. **Interactive Paper Trading Terminal:** Full simulation engine allowing users to accept setups, simulate custom entries, track mark-to-market valuations, record realized P&L, and measure paper win rates.
10. **Modern React & TypeScript Dashboard:** Institutional dark-mode interface with charts, setup explainability drawers, and health inspection.

## Quickstart Guide

### Prerequisites
- Python 3.12+
- Node.js 18+ and npm
- (Optional) Docker & Docker Compose for PostgreSQL containerization

### 1. Environment Setup

```bash
# Clone the repository
git clone <repo-url>
cd "Trading Scanner"

# Create and activate Python virtual environment
python3.12 -m venv .venv
source .venv/bin/activate

# Install backend dependencies
pip install --upgrade pip
pip install -e ".[dev,api]" pyarrow

# Configure environment variables
cp .env.example .env
```

### 2. Run Unit & Look-Ahead Tests

```bash
pytest -v
```

### 3. Run the CLI Scanner

Scan NIFTY 50 for the latest trading day:
```bash
python -m scanner.scan --universe NIFTY_50 --top 10
```

Scan with custom capital (e.g., ₹2,00,000) and risk (e.g., 0.75%):
```bash
python -m scanner.scan --universe NIFTY_100 --capital 200000 --risk-pct 0.0075 --top 5
```

Scan for a specific historical date:
```bash
python -m scanner.scan --date 2024-05-10 --universe NIFTY_50
```

### 4. Start the FastAPI Backend

```bash
python -m uvicorn scanner.api.main:app --host 0.0.0.0 --port 8000 --reload
```
Swagger API docs available at: [http://localhost:8000/docs](http://localhost:8000/docs)

### 5. Start the React Frontend

```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## Docker Deployment

To launch the complete stack (PostgreSQL + FastAPI + React Frontend in Nginx):

```bash
docker-compose up --build
```
- Frontend: [http://localhost:3000](http://localhost:3000)
- Backend API: [http://localhost:8000](http://localhost:8000)
- Database: `localhost:5432`

├── .env.example                # Sample environment configurations
├── Dockerfile                  # Backend container specification
├── Dockerfile.frontend         # Production frontend container specification
├── docker-compose.yml          # Multi-container orchestration
├── alembic/                    # Database migrations
├── scanner/                    # Core Python application
│   ├── config.py               # Pydantic Settings & configuration
│   ├── models/                 # SQLAlchemy ORM models (Instrument, OHLCV, Signal, etc.)
│   ├── providers/              # MarketDataProvider interface & Yahoo Finance implementation
│   ├── data/                   # Universes, DataValidator, DataLoader with Parquet caching
│   ├── indicators/             # IndicatorCalculator (point-in-time ta math)
│   ├── regime/                 # MarketRegimeEngine (NIFTY 50 bias classifier)
│   ├── strategies/             # TREND_PULLBACK_V1 strategy implementation
│   ├── risk/                   # PositionSizer & Portfolio risk manager
│   ├── backtest/               # Event-driven backtester, Indian equity costs, Walk-forward
│   ├── paper/                  # PaperTradingEngine simulation & persistence
│   ├── api/                    # FastAPI routers (scan, regime, stocks, backtest, paper)
│   └── scan.py                 # CLI entry point
├── frontend/                   # React + TypeScript terminal
│   ├── src/pages/              # Dashboard, Scanner, StockDetail, Backtest, PaperTrading, Health
│   └── src/components/         # Navbar, Recharts charts, Setup modals
└── tests/                      # Pytest suite (indicators, strategy, lookahead, costs, etc.)
